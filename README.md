# Hospital-DB
Hospital workflow simulation featuring role-based access, patient history tracking, and doctor performance analytics and advanced SQL queries.
A lightweight, effective Hospital Management System built with a **PHP/JS** frontend and a **Relational SQL** backend. 

## 🚀 Overview
This project simulates a real-world hospital environment, focusing on role-based workflows and complex data relationships. It is hosted locally using **XAMPP**, ensuring an interactive and responsive user experience.

## 🛠 Tech Stack
* **Frontend:** HTML5, CSS3, JavaScript
* **Backend:** PHP
* **Database:** SQL (SQL Server)
* **Server:** XAMPP (Apache)

## 📋 Key Features
* **Multi-Role Workflow:** Distinct functionalities for Doctors, Nurses, and Consultants.
* **Ward Management:** Tracking of Care Units, wards, and bed records.
* **Patient Lifecycle:** Maintains detailed history of treatments, complaints, and medical records.
* **Performance Tracking:** A specialized module for Consultants to judge and record the performance history and experience of their medical teams.

## 📊 Database Intelligence
The system utilizes **12 advanced SQL queries** to manage data integrity and generate meaningful reports, specifically focusing on the hierarchy between consultants and doctors.

## ⚙️ How to Run Locally
1. Install **XAMPP**.
2. Clone this repo into your `htdocs` directory.
3. Open **XAMPP Control Panel** and start Apache and MySQL.
4. Import the provided `.sql` file via **phpMyAdmin**.
5. Navigate to `http://localhost/[your-repo-name]` in your browser.
